How this was checked

Mutants are deliberate breaks planted in the app: bugs change behaviour, refactors change only markup. The same command runs both suites against every mutant, and each verdict comes from exit codes and run results, never from the agent's word. The coding agent never sees the mutant, only what the old test asserted and what Kane did, so it cannot tune a test to the break.
